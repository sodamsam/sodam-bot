# 일주일 식단 프롬프트 5종
"오늘 뭐 먹지"를 매일 고민하지 마세요. 냉장고 재료만 알려주면 일주일이 정리돼요.

## 쓰는 법
1. 회색 상자 오른쪽 위 복사 버튼을 누르세요
2. 챗GPT 입력창에 붙여넣으세요
3. [대괄호] 부분만 내 내용으로 바꾸면 끝입니다

## 1. 냉장고 재료 정리하기
**이럴 때 씁니다** — 냉장고에 뭐가 있는지도 헷갈릴 때
```
지금 냉장고와 찬장에 있는 재료는 이거야.
[여기에 있는 재료를 생각나는 대로 나열]

이 재료들을 "채소 / 고기·생선 / 곡류·가공식품"으로 분류해줘.
분류마다 목록으로 정리해줘.
없는 내용은 지어내지 마.
```
**더 좋게 쓰는 법** — 유통기한이 임박한 재료가 있으면 "이건 이번 주에 꼭 써야 해"라고 표시해두세요.

## 2. 일주일 식단표 만들기
**이럴 때 씁니다** — 정리된 재료로 실제 일주일 메뉴를 짤 때
```
아래는 지금 집에 있는 재료야.
[여기에 1번 결과 붙여넣기]
가족 수: [여기에 인원수]

이 재료 위주로 월~일 저녁 메뉴를 짜줘.
표로 만들어줘. 열은 "요일 / 메뉴"로 해줘.
같은 메뉴가 이틀 연속 나오지 않게 해줘.
없는 내용은 지어내지 마.
```
**더 좋게 쓰는 법** — 아침·점심까지 필요하면 "아침, 점심 메뉴도 추가해줘"라고 요청하세요.

## 3. 부족한 재료 장보기 목록 뽑기
**이럴 때 씁니다** — 식단표는 나왔는데 뭘 더 사야 할지 모를 때
```
아래는 이번 주 식단표와 지금 있는 재료야.
식단표: [여기에 2번 결과 붙여넣기]
있는 재료: [여기에 1번 결과 붙여넣기]

식단표대로 만들려면 추가로 사야 할 재료를 뽑아줘.
목록으로 정리해주고, 대략적인 수량도 같이 적어줘.
이미 있는 재료는 목록에서 빼줘.
없는 내용은 지어내지 마.
```
**더 좋게 쓰는 법** — 근처 마트나 온라인 장보기 앱에 맞춰 "마트 코너별로 묶어줘"라고 요청하면 더 편해요.

## 4. 조리 순서 정리하기
**이럴 때 씁니다** — 메뉴는 정했는데 요일마다 뭘 먼저 준비해야 할지 헷갈릴 때
```
아래는 이번 주 식단표야.
[여기에 2번 결과 붙여넣기]

각 요일 메뉴마다 대략적인 조리 순서를 3단계로 정리해줘.
너무 전문적인 요리 용어는 쓰지 말고 쉬운 말로 써줘.
번호를 붙여서 요일별로 구분해줘.
없는 내용은 지어내지 마.
```
**더 좋게 쓰는 법** — 시간이 부족한 요일이 있으면 "그 요일은 15분 이내로 되는 방법으로"라고 조건을 붙이세요.

## 5. 예산 점검하기
**이럴 때 씁니다** — 장보기 전에 이번 주 식비가 얼마나 나올지 가늠하고 싶을 때
```
아래는 이번 주 장보기 목록이야.
[여기에 3번 결과 붙여넣기]
목표 예산: [여기에 목표 금액]

이 목록으로 대략적인 예상 금액을 항목별로 어림잡아줘.
정확한 가격은 모르니 "대략"이라고 표시해줘.
목표 예산을 넘길 것 같으면 줄일 만한 항목을 알려줘.
없는 내용은 지어내지 마.
```
**더 좋게 쓰는 법** — 실제 영수증 금액을 알게 되면 다음 주에 "지난주엔 이 가격이었어"라고 알려주면 더 정확해져요.

## 잘 안 될 때
- 메뉴가 계속 반복돼요 → "최근에 나온 메뉴는 빼고 다시 짜줘"라고 요청하세요
- 아이 입맛까지 고려가 안 돼요 → 1번 프롬프트에 "아이가 매운 음식을 못 먹어" 같은 조건을 추가하세요
- 장보기 목록이 너무 길어요 → "우선순위가 높은 5개만 추려줘"를 추가하세요
- 예상 금액이 실제와 너무 달라요 → "정확한 금액이 아니라 대략적인 감이라는 걸 다시 알려줘"라고 요청하세요
