# 회의록 정리 프롬프트 5종
회의 끝나고 멍하니 녹취록만 쳐다보고 계셨죠. 이 5개만 순서대로 쓰면 정리부터 팀 공유까지 끝나요.

## 쓰는 법
1. 회색 상자 오른쪽 위 복사 버튼을 누르세요
2. 챗GPT 입력창에 붙여넣으세요
3. [대괄호] 부분만 내 내용으로 바꾸면 끝입니다

## 1. 녹음·메모 재료 정리하기
**이럴 때 씁니다** — 녹취록이나 손메모가 뒤죽박죽이라 뭐부터 봐야 할지 모를 때
```
아래는 회의 중 적은 메모 또는 녹취 내용이야.
[여기에 회의 메모나 녹취록 붙여넣기]

이 내용을 시간 순서대로 다시 정리해줘.
같은 주제끼리는 묶어서 정리해줘.
사람 이름이 나오면 그대로 남겨줘.
번호를 붙여서 목록으로 출력해줘.
없는 내용은 지어내지 마.
```
**더 좋게 쓰는 법** — 메모가 너무 길면 앞부분만 먼저 넣고 나눠서 여러 번 돌리세요.

## 2. 핵심만 뽑아 회의록 만들기
**이럴 때 씁니다** — 1번에서 정리한 내용을 실제 회의록 형태로 바꿀 때
```
아래는 방금 정리한 회의 내용이야.
[여기에 1번 결과 붙여넣기]

이 내용으로 회의록을 만들어줘.
형식은 "안건 / 논의 내용 / 결정 사항" 3줄로 구분해줘.
안건마다 이 형식을 반복해줘.
전체 500자를 넘기지 마.
없는 내용은 지어내지 마.
```
**더 좋게 쓰는 법** — 안건이 여러 개면 "안건별로 번호를 붙여줘"를 한 줄 추가하세요.

## 3. 실행할 일(액션아이템) 뽑기
**이럴 때 씁니다** — 회의는 끝났는데 누가 뭘 해야 하는지 흩어져 있을 때
```
아래는 오늘 회의록이야.
[여기에 2번 결과 붙여넣기]

이 중에서 실제로 해야 할 일만 뽑아줘.
표로 만들어줘. 열은 "할 일 / 이유"로 해줘.
회의록에 없는 할 일은 만들지 마.
없는 내용은 지어내지 마.
```
**더 좋게 쓰는 법** — "이유"가 불필요하면 "할 일만 한 줄씩 적어줘"로 바꾸세요.

## 4. 담당자·기한 배정해서 정리하기
**이럴 때 씁니다** — 할 일 목록에 담당자와 기한까지 붙여서 공유해야 할 때
```
아래는 이번 회의에서 나온 할 일 목록이야.
[여기에 3번 결과 붙여넣기]
담당자 후보: [여기에 팀원 이름 나열]

각 할 일에 담당자를 배정해줘. 특별한 언급이 없으면 "미정"으로 남겨줘.
기한 칸도 추가해줘. 언급된 기한이 없으면 "미정"으로 적어줘.
표로 출력해줘. 열은 "할 일 / 담당자 / 기한"으로 해줘.
없는 내용은 지어내지 마.
```
**더 좋게 쓰는 법** — 실제 기한이 회의록에 있으면 3번 결과에 미리 적어두면 더 정확해요.

## 5. 팀 공유용 메시지로 바꾸기
**이럴 때 씁니다** — 정리한 회의록을 단체 카톡이나 메신저로 보내야 할 때
```
아래는 오늘 회의록과 할 일 목록이야.
[여기에 2번과 4번 결과 붙여넣기]

이 내용을 팀 단체 메시지로 보낼 수 있게 3줄로 요약해줘.
말투는 정중한 존댓말로 해줘.
이모지는 쓰지 마.
없는 내용은 지어내지 마.
```
**더 좋게 쓰는 법** — 카톡용이 아니라 이메일용이면 "이메일 형식으로 바꿔줘"라고 덧붙이세요.

## 잘 안 될 때
- 결과가 너무 길게 나와요 → "전체 500자 이내로 줄여줘"를 마지막 줄에 추가하세요
- 회의에 없는 내용을 지어내요 → "모르는 부분은 [확인 필요]라고 표시해줘"를 추가하세요
- 표가 깨져서 나와요 → "마크다운 표 말고 줄글로 다시 써줘"라고 요청하세요
- 존댓말이 아니라 반말로 나와요 → "정중한 존댓말로 다시 써줘"라고 한 번 더 요청하세요
