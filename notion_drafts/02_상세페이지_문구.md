# 상세페이지 문구 프롬프트 5종
빈 화면 앞에서 "뭐라고 써야 하지" 고민하던 시간, 이 5개면 확 줄어들어요.

## 쓰는 법
1. 회색 상자 오른쪽 위 복사 버튼을 누르세요
2. 챗GPT 입력창에 붙여넣으세요
3. [대괄호] 부분만 내 내용으로 바꾸면 끝입니다

## 1. 상품 특징 재료 정리하기
**이럴 때 씁니다** — 좋은 점은 많은데 뭐부터 써야 할지 막막할 때
```
내가 파는 상품은 [여기에 상품 이름과 간단한 설명]이야.
장점: [여기에 장점 나열, 아는 대로 적어도 됨]
가격: [여기에 가격]

위 내용을 바탕으로 이 상품의 장점 5가지를 짧은 문장으로 정리해줘.
번호를 붙여서 목록으로 출력해줘.
없는 내용은 지어내지 마.
```
**더 좋게 쓰는 법** — 장점이 잘 안 떠오르면 "고객이 왜 이걸 사는지 이유 3개도 물어봐줘"를 추가하세요.

## 2. 상세페이지 본문 초안 쓰기
**이럴 때 씁니다** — 1번에서 정리한 장점으로 실제 상세페이지 글을 만들 때
```
아래는 내 상품의 장점 목록이야.
[여기에 1번 결과 붙여넣기]

이 내용으로 상세페이지 본문을 써줘.
순서는 "한 줄 소개 → 장점 3가지 → 이런 분께 추천" 순서로 해줘.
전체 400자 이내로 써줘.
없는 내용은 지어내지 마.
```
**더 좋게 쓰는 법** — 브랜드 톤이 있으면 "친근한 반말로" 또는 "정중한 존댓말로"를 지정하세요.

## 3. 후킹 헤드라인 다듬기
**이럴 때 씁니다** — 본문은 됐는데 첫 줄이 눈에 안 띌 때
```
아래는 내 상품 상세페이지 본문이야.
[여기에 2번 결과 붙여넣기]

이 상품을 대표하는 헤드라인 문구를 5개 만들어줘.
각 문구는 15자 이내로 써줘.
번호를 붙여서 목록으로 출력해줘.
과장된 표현("최고", "무조건")은 쓰지 마.
없는 내용은 지어내지 마.
```
**더 좋게 쓰는 법** — 마음에 드는 게 없으면 "3번, 4번 스타일로 5개 더"라고 요청하세요.

## 4. 신뢰 요소 추가해 확장하기
**이럴 때 씁니다** — 후기나 보장 내용을 자연스럽게 녹여 넣고 싶을 때
```
아래는 내 상세페이지 본문이야.
[여기에 2번 결과 붙여넣기]
추가할 신뢰 정보: [여기에 후기 수, 배송 정책, 교환·환불 조건 등]

위 신뢰 정보를 본문 마지막에 자연스럽게 한 단락 추가해줘.
과장하지 말고 사실 그대로만 적어줘.
전체 500자를 넘기지 마.
없는 내용은 지어내지 마.
```
**더 좋게 쓰는 법** — 신뢰 정보가 없으면 이 단계는 건너뛰고 5번으로 가도 괜찮아요.

## 5. 최종 점검하기
**이럴 때 씁니다** — 올리기 전에 어색한 부분이 없는지 마지막으로 확인할 때
```
아래는 내가 완성한 상세페이지 본문이야.
[여기에 4번 결과 붙여넣기]

아래 4가지를 점검해서 표로 알려줘.
1) 어색한 문장이 있는지
2) 과장된 표현이 있는지
3) 너무 긴 문장이 있는지
4) 오타로 보이는 부분이 있는지
문제가 없으면 "문제 없음"이라고 적어줘.
없는 내용은 지어내지 마.
```
**더 좋게 쓰는 법** — 점검 결과에서 지적된 부분만 따로 복사해서 "이 부분만 다시 써줘"라고 요청하세요.

## 잘 안 될 때
- 문구가 너무 과장돼요 → "과장된 표현은 전부 빼줘"라고 다시 요청하세요
- 너무 딱딱한 말투로 나와요 → "더 친근한 말투로 다시 써줘"를 추가하세요
- 글자 수가 자꾸 넘쳐요 — "OO자 이내"라고 숫자를 더 구체적으로 지정하세요
- 상품마다 새로 쓰기 귀찮아요 → 1번 프롬프트의 [대괄호]만 바꿔서 계속 재사용하세요
