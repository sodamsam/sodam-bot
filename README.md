# 스레드 자동화 봇 (댓글 자동응답 + 매일 자동 발행)

@sodam_ai_lab 스레드 계정을 위한 무인 자동화 세트입니다. **PC를 켜둘 필요 없이** GitHub Actions에서 무료로 돌아갑니다.

1. **댓글 자동응답**: 게시물에 키워드 댓글이 달리면 노션 DB에서 맞는 자료를 찾아 대댓글로 링크 전달
2. **매일 자동 발행**: 아침 7시대에 "밤사이 AI 소식"(최신 AI 뉴스 해석), 저녁 19시대에 "AI로 이렇게 바뀌었어요"(노션에 적어둔 실제 AI 활용 경험, 없으면 뉴스 기반 활용팁으로 대체)를 AI가 작성해 자동 게시 — 뉴스는 구글 뉴스 RSS(무료), 글 작성은 Gemini 무료 API 사용

> **중요(무료 유지)**: GitHub 저장소를 **Public(공개)** 으로 만드세요. 공개 저장소는 Actions 실행 시간이 무제한 무료입니다. 비공개는 월 2,000분 제한이 있어 10분 주기 봇이 한도를 넘습니다. 토큰·키는 전부 Secrets에 저장되므로 코드가 공개돼도 유출되지 않습니다.

---

## 전체 설치 순서 (처음 1회만)

### 1단계. Meta 개발자 앱 만들기 (스레드 토큰 발급)

1. https://developers.facebook.com 접속 → 우측 상단 로그인 (인스타/페이스북 계정)
2. [내 앱] → [앱 만들기] → 사용 사례에서 **"Threads API 액세스"** 선택 → 앱 이름 아무거나(예: sodam-bot) 입력 → 생성
3. 왼쪽 메뉴 [사용 사례] → Threads API [설정] → 권한에서 아래 4개를 **추가**:
   - `threads_basic`
   - `threads_content_publish`
   - `threads_read_replies`
   - `threads_manage_replies`
4. [Threads API] → [설정] 화면에서 **"액세스 토큰 생성기"** 또는 테스트 사용자 추가 후, @sodam_ai_lab 계정으로 로그인/승인하여 **액세스 토큰**을 발급받습니다.
5. 발급된 토큰을 **장기 토큰(60일)** 으로 교환합니다. (앱 설정의 "토큰 교환" 기능 사용, 또는 docs/03_API_설명서.md 참고)
6. 토큰을 메모장에 임시 보관 → 아래 4단계에서 GitHub에 등록

> 토큰은 60일마다 갱신이 필요합니다. 갱신 방법은 아래 "토큰 갱신" 참고.

### 2단계. 노션 준비 (자료 DB + 연동 토큰)

1. https://www.notion.so/my-integrations 접속 → [새 API 통합 만들기] → 이름: sodam-bot → 생성
2. **"프라이빗 API 통합 시크릿"** 을 복사해 임시 보관 (`ntn_...` 으로 시작) → 이것이 `NOTION_TOKEN`
3. 노션에서 자료를 모아둘 **데이터베이스(표)** 를 하나 만듭니다. 속성 구성:
   - **이름** (제목): 자료 제목 — 예: "AI 블로그 글쓰기 프롬프트 모음"
   - **키워드** (텍스트): 이 자료를 받을 댓글 키워드 — 예: "프롬프트"
4. DB 페이지 우측 상단 [⋯] → [연결] → 방금 만든 **sodam-bot 연동을 추가** (이걸 안 하면 봇이 DB를 못 읽습니다!)
5. DB 링크를 복사하면 주소가 `notion.so/내이름/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx?v=...` 형태인데, 이 중 **32자리 영문+숫자 부분**이 `NOTION_DATABASE_ID` 입니다.

### 3단계. Gemini 무료 API 키 발급 (자동 발행용)

1. https://aistudio.google.com 접속 → 구글 계정 로그인
2. 좌측 [Get API key] → [API 키 만들기] → 키 복사 (`AIza...` 형태)
3. 카드 등록 없이 무료 등급으로 사용됩니다 (하루 발행 2회는 무료 한도의 극히 일부)

### 4단계. GitHub 저장소 만들기

1. https://github.com 가입/로그인 → [New repository]
2. 이름: `threads-notion-bot`, **Public(공개)** 선택 → 생성 (Actions 무제한 무료를 위해)
3. 이 폴더의 파일 전체를 업로드: [uploading an existing file] 클릭 → 폴더 안 파일 전부 드래그
   - `.github/workflows/` 폴더 구조가 유지되어야 합니다. 웹 업로드로 폴더 구조가 안 잡히면, [Add file] → [Create new file]에서 파일명을 `.github/workflows/comment_bot.yml` 처럼 경로째 입력해 내용 붙여넣기 하면 됩니다.

### 5단계. Secrets(비밀값) 등록

저장소 → [Settings] → [Secrets and variables] → [Actions] → [New repository secret] 으로 4개 등록:

| 이름 | 값 |
|---|---|
| `THREADS_ACCESS_TOKEN` | 1단계에서 발급한 스레드 장기 토큰 |
| `NOTION_TOKEN` | 2단계의 노션 시크릿 (ntn_...) |
| `NOTION_DATABASE_ID` | 2단계의 DB ID (32자리) |
| `GEMINI_API_KEY` | 3단계의 Gemini 키 (AIza...) |
| `NOTION_EVENING_DB_ID` *(선택)* | 저녁 소재 노트 DB ID. 안 넣으면 기본값으로 동작 |

### 6단계. 작동 확인

1. 저장소 [Actions] 탭 → 왼쪽 "댓글 감시 봇" → [Run workflow] 버튼으로 수동 실행
2. 초록색 체크가 뜨면 성공. 로그를 열면 `[노션] 자료 N개 로드` 같은 메시지가 보입니다.
3. 스레드 게시물에 다른 계정으로 키워드 댓글을 달아 테스트해 보세요. 다음 실행 회차(최대 10분)에 대댓글이 달립니다.
4. **자동 발행 테스트**: [Actions] → "매일 자동 글 발행" → [Run workflow] → morning 또는 evening 선택 → 실행하면 그 자리에서 바로 1개 발행됩니다. 결과가 마음에 안 들면 스레드에서 지우면 돼요.

## 평소 사용법

- **자료 추가**: 노션 DB에 행 하나 추가 (이름 + 키워드 + 페이지 내용 작성) → 끝. 봇이 자동으로 반영합니다.
- **글 발행**: 스레드 앱에서 직접 써도 되고, GitHub [Actions] → "스레드 글 발행" → [Run workflow]에 글 내용을 넣어 발행해도 됩니다.
- **자동 발행**: 설정 후엔 아무것도 안 해도 됩니다. 매일 아침 7시대, 저녁 19시대에 1개씩 올라갑니다. 저녁 글은 노션 "저녁 소재 노트" DB에 미사용 메모가 있으면 그 내용을 우선 사용하고, 없으면 뉴스 기반으로 자동 대체됩니다. 발행된 글이 마음에 안 들면 스레드 앱에서 지우면 끝.
- **저녁 소재 채우기**: 노션 "저녁 소재 노트" DB에 행을 추가하고 이름/날짜/상황/ai활용/변화·결과를 적어두면(사용여부는 "미사용"), 저녁 자동 발행이 오래된 순서로 하나씩 가져다 씁니다. 자세한 DB 구조는 `docs/06_AI_개발_가이드.md` 참고.
- **키워드 동작 방식**:
  - 댓글에 특정 자료의 키워드(예: "프롬프트")가 있으면 → 그 자료 링크 전송
  - 키워드 없이 "신청"만 있으면 → **가장 최근에 추가한** 노션 페이지 링크 전송
  - 답장 문구를 바꾸고 싶으면 `config.py`의 `REPLY_TEMPLATE` 수정

## 토큰 갱신 (60일마다)

만료 전에 로컬 PC에서 `python refresh_token.py` 를 실행하거나, 간단하게는 Meta 개발자 페이지에서 토큰을 다시 발급받아 GitHub Secrets의 `THREADS_ACCESS_TOKEN` 값을 교체하면 됩니다. 만료되면 봇이 멈추고 Actions 로그에 오류가 표시됩니다.

## 문제가 생기면

[Actions] 탭에서 빨간 X가 뜬 실행을 열어 로그를 복사한 뒤, AI(Claude 등)에게 `docs/06_AI_개발_가이드.md` 와 함께 보여주면 이어서 해결할 수 있습니다.
