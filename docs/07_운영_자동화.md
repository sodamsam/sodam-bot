# ⑦ 운영 자동화 (PC가 꺼져 있어도 돌아가는 구조)

소담봇은 **전부 GitHub 서버에서 실행**됩니다. 내 PC는 코드를 고칠 때만 필요하고, 꺼져 있어도 발행·댓글응답에는 영향이 없습니다.

## 무엇이 무엇을 깨우나

| 작업 | 깨우는 주체 | 실제 호출 간격(실행 기록 기준) | PC 필요 |
|---|---|---|---|
| 매일 자동 글 발행 | **cron-job.org**(외부 서비스)가 GitHub API로 workflow_dispatch 호출 + GitHub 자체 스케줄(보조) | 07:00·07:20·07:40 / 19:00·19:20·19:40 KST에 호출(실행 기록상 추정, cron-job.org 설정 화면은 확인 못 함) | 아니오 |
| 댓글 감시 봇 | GitHub 자체 스케줄만 | 설정은 10분이지만 **실제로는 2.4~5.5시간 간격** (GitHub 무료 스케줄이 밀림) | 아니오 |
| 건강검진 (`health_check.yml`) | GitHub 스케줄 | 매일 KST 21:10 | 아니오 |
| Threads 토큰 자동 연장 (`refresh_token.yml`) | GitHub 스케줄 | 2주마다(UTC 1일·15일) | 아니오 |

> GitHub의 `schedule`은 "정각에 보장"이 아니라 "혼잡하면 한참 밀리거나 건너뜀"입니다. 그래서 시간이 중요한 발행은 외부 서비스(cron-job.org)가 직접 호출하는 방식을 함께 씁니다. **댓글봇에는 이 보강이 아직 없어서**, "신청" 댓글에 답이 몇 시간씩 늦는 원인이 됩니다.

## 해야 할 일 (사용자가 직접)

### 1. 권한 토큰(PAT) 새로 만들기 — 기존 `sodam-bot-cron`은 10월 28일 만료

이 토큰이 만료되면 cron-job.org 호출이 전부 실패합니다(GitHub 자체 스케줄만 남아 발행이 불안정해짐). 하나를 새로 만들어 두 곳에 씁니다.

1. https://github.com/settings/personal-access-tokens/new
2. Token name: `sodam-bot-ops` / Expiration: **1 year**(가능한 최대) / Repository access: **Only select repositories → sodam-bot**
3. Repository permissions: **Actions: Read and write**, **Secrets: Read and write** (Metadata는 자동으로 Read)
4. 생성된 값을 복사해 아래 두 곳에 붙여넣기 (이 값은 화면에 한 번만 보입니다. 채팅에는 붙여넣지 마세요)
   - **cron-job.org**: 기존 작업들의 Authorization 헤더(`Bearer 값`)를 교체
   - **GitHub Secrets**: 저장소 → Settings → Secrets and variables → Actions → New repository secret → 이름 `GH_ADMIN_TOKEN`

### 2. cron-job.org에 댓글봇 호출 추가 (10분 간격)

| 항목 | 값 |
|---|---|
| URL | `https://api.github.com/repos/sodamsam/sodam-bot/actions/workflows/comment_bot.yml/dispatches` |
| Method | POST |
| Schedule | 10분마다 (Every 10 minutes) |
| Headers | `Authorization: Bearer (PAT 값)` / `Accept: application/vnd.github+json` / `X-GitHub-Api-Version: 2022-11-28` |
| Body | `{"ref":"main"}` |

댓글봇은 `concurrency`와 `replied.json`으로 중복 실행·중복 답장이 막혀 있어 호출이 겹쳐도 안전합니다. GitHub 자체 스케줄은 보조로 그대로 둡니다.

### 3. 내 PC 폴더 자동 최신화 (선택)

PC가 꺼져 있던 동안의 변경도 켜면 따라잡습니다. 수정 중인 파일은 덮어쓰지 않는 `--ff-only` 방식입니다. PowerShell에서 한 번만 실행:

```
schtasks /Create /TN "SodamBot-Sync" /SC MINUTE /MO 30 /TR "cmd /c git -C C:\Users\heaco\claude-projects\projects\sodam-bot pull --ff-only origin main" /F
```

해제: `schtasks /Delete /TN "SodamBot-Sync" /F`

## 이상이 생기면

- **건강검진이 실패 메일을 보냄** → 그 실행의 요약(Summary)에 어떤 항목이 왜 실패했는지 한 줄씩 나옵니다. "오늘 발행 기록 없음"이면 `auto_post` 로그를, "토큰 오류"면 Meta 앱 → Threads API → 설정 → "액세스 토큰 생성하기"로 새 토큰을 받아 `THREADS_ACCESS_TOKEN`을 교체하세요.
- **토큰 자동 연장이 실패** → `GH_ADMIN_TOKEN` 미등록/만료이거나, Threads 토큰이 이미 만료된 경우입니다. 후자면 위와 같이 새 토큰을 수동 발급하세요.
- 알림 메일이 안 오면 GitHub → Settings → Notifications → Actions에서 "Send notifications for failed workflows only"가 켜져 있는지 확인하세요.
