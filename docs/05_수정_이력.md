## 2026-11-15 — 카드 디자인 v3 (검정 뉴스 카드 + 크림 프롬프트 카드)
- 배경: 보랏빛 카드가 피드에서 눈에 띄지 않는다는 사용자 요청. AI 정보 계정(@ai_margin_)의 그리드를 참고해 "검정 정보형"과 "크림 손글씨형" 두 가지 얼굴로 바꿈. 로고·캐릭터·문구는 베끼지 않고 소담 것으로 새로 만듦
- 뉴스 카드(`generate_news_card`): 검정 바탕 + 흰 굵은 글씨 + 주황 뱃지·행동 박스 + 보라 번호(01·02·03). 제목에서 숫자가 든 어절(3가지, 10분 등)은 자동으로 주황색
- 복붙 프롬프트 4장(`generate_prompt_slides`): 크림색 바탕 + 남색 둥근 제목 글꼴(Jua) + 주황 강조 + 표지 첫 줄 노란 형광펜 + 소담 마스코트(웃는 그릇, 도형으로 직접 그림)
- 글자 가장자리가 매끄럽도록 2배로 그린 뒤 1080×1350으로 줄여 저장
- 함수 이름·카드 데이터 형식은 그대로라 `auto_post.py`·`corners.py`는 수정 없음. 사진이나 직접 올리는 이미지는 여전히 필요 없음(글 → 카드 자동 생성)
- 글꼴 추가: `fonts/Jua-Regular.ttf` (SIL OFL 무료 글꼴, 라이선스는 `fonts/OFL-Jua.txt`)
- 테스트 164개 그대로 통과
