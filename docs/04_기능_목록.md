# ④ 기능 목록

## 구현 완료 (v2.x)

| 번호 | 기능 | 설명 | 파일 |
|---|---|---|---|
| F-01 | 댓글 자동 감시 | 최근 게시물 5개의 댓글을 10분마다 확인 | comment_bot.py |
| F-02 | 키워드 매칭 | 노션 페이지별 키워드 매칭 (긴 키워드 우선), 기본 키워드 "신청" 시 허브 페이지 전송 | notion_api.match_page |
| F-03 | 노션 자료 연동 | 노션 DB에 페이지 추가만 하면 봇이 자동 반영 | notion_api.get_pages |
| F-04 | 자동 대댓글 발송 | 매칭된 자료 제목+링크를 템플릿 문구로 대댓글 발행 | threads_api.publish_text |
| F-05 | 중복 답장 방지 | 답장한 댓글 ID를 state/replied.json에 기록, 저장소 커밋 | comment_bot.py |
| F-06 | 자기 댓글 무시 | 내 계정(@sodam_ai_lab)이 단 댓글은 건너뜀 | comment_bot.py |
| F-07 | 수동 글 발행 | GitHub Actions 버튼 또는 로컬 실행으로 스레드 글 게시 | post_thread.py, post.yml |
| F-08 | 무인 주기 실행 | GitHub Actions cron 10분 주기, 수동 실행 버튼 포함 | comment_bot.yml |
| F-09 | 토큰 갱신 도우미 | 60일 장기 토큰 갱신 스크립트(이미 살아있는 토큰 연장용). 완전히 새로 받을 땐 Meta 앱의 "사용자 토큰 생성기"가 더 빠름 | refresh_token.py |
| F-10 | 매일 자동 발행 | 아침 7~9시대(1순위)/저녁 18~20시대(2순위), 하루 1회 자동 게시 | auto_post.py, auto_post.yml |
| F-11 | 뉴스 자동 수집 | 구글 뉴스 RSS로 최신 기사 수집, 발행 시각 불명 기사 제외, 중복 제거 | auto_post.fetch_news |
| F-12 | AI 글 작성 | Gemini 무료 API로 뉴스 기반 스레드 글 생성 | auto_post._call_gemini |
| F-13 | 스팸 패턴 회피 | 답장 문구 랜덤, 회차당 4개 상한, 답장 간 20~50초 간격 | config.py, comment_bot.py |
| F-14 | 발행 안정화 대기 | 컨테이너 생성 후 30초(대댓글·이미지 컨테이너는 상황에 맞게) 대기 — 공식 권장 반영 | threads_api.publish_text, publish_image |
| F-15 | 정부·지자체 AI 지원 혜택 코너 | 신선도 4점 만점(신설·규모·긴급성·신청방법) 3점 이상 + 신청 정보 확인된 소재만 채택, 환각 검증 2단계 통과해야 발행 | auto_post.pick_benefit_item, write_benefit_post, find_fabrications |
| F-16 | 프롬프트 나눔 OPEN/LEAD 큐 | 요일별로 프롬프트 전문 공개(OPEN)/맛보기+신청유도(LEAD) 배분. **LEAD는 현재 LEAD_ENABLED=False로 꺼져 있어 전부 OPEN으로 나감** | auto_post.WEEKDAY_TYPE_MAP, LEAD_ENABLED, write_queued_prompt_post, prompt_queue.py |
| F-17 | 업무 활용법 코너 | 주 1회(POST_CYCLE), 노션 자료와 무관하게 자체 글감 은행에서 순환 | auto_post.write_howto_post |
| F-18 | AI 브리핑 카드뉴스 | 주 1회, 정책·규제·서비스 변화 뉴스를 카드 이미지(소담 브랜드 가이드 기반)+캡션으로 발행. 서로 다른 기사 2건 이상 교차 확인 + 정책 신호어 점수제 + 환각 검증 2단계 통과 필요, 없으면 자동으로 업무 활용법으로 대체 | card_news.py, auto_post.pick_briefing_item, write_briefing_post, run_briefing |
| F-19 | 카드 이미지 자동 공개 | 생성한 카드 PNG를 GitHub 저장소에 즉시 커밋·푸시해 raw.githubusercontent.com URL로 Threads에 전달 | auto_post._publish_card_image |
| F-20 | 발행 시간대/타입 강제 테스트 | workflow_dispatch로 시간대 판단 없이 즉시 발행(force_window), post_type을 open/lead/briefing 중 하나로 강제 지정 가능 | auto_post.yml, auto_post.main |
| F-21 | 7일 순환 큐 | 요일에 고정하지 않아 발행이 누락돼도 순서만 밀리고 깨지지 않음. 프롬프트(5)·브리핑(1)·업무활용법(1) 배분 | auto_post.POST_CYCLE |
