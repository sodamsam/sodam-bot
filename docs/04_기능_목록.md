# ④ 기능 목록

## 구현 완료 (v1.6)

| 번호 | 기능 | 설명 | 파일 |
|---|---|---|---|
| F-01 | 댓글 자동 감시 | 최근 게시물 5개의 댓글을 10분마다 확인 | comment_bot.py |
| F-02 | 키워드 매칭 | 노션 페이지별 키워드 매칭 (긴 키워드 우선), 기본 키워드 "신청" 시 최신 자료 | notion_api.match_page |
| F-03 | 노션 자료 연동 | 노션 DB에 페이지 추가만 하면 봇이 자동 반영 | notion_api.get_pages |
| F-04 | 자동 대댓글 발송 | 매칭된 자료 제목+링크를 템플릿 문구로 대댓글 발행 | threads_api.publish_text |
| F-05 | 중복 답장 방지 | 답장한 댓글 ID를 state/replied.json에 기록, 저장소 커밋 | comment_bot.py |
| F-06 | 자기 댓글 무시 | 내 계정(@sodam_ai_lab)이 단 댓글은 건너뜀 | comment_bot.py |
| F-07 | 수동 글 발행 | GitHub Actions 버튼 또는 로컬 실행으로 스레드 글 게시 | post_thread.py, post.yml |
| F-08 | 무인 주기 실행 | GitHub Actions cron 10분 주기, 수동 실행 버튼 포함 | comment_bot.yml |
| F-09 | 토큰 갱신 도우미 | 60일 장기 토큰 갱신 스크립트 | refresh_token.py |
| F-10 | 매일 자동 발행 | 아침 7시대 / 저녁 19시대, 하루 2회 자동 게시 | auto_post.py, auto_post.yml |
| F-11 | 뉴스 자동 수집 | 구글 뉴스 RSS로 AI 최신 기사 수집, 중복 제외 | auto_post.fetch_news |
| F-12 | AI 글 작성 | Gemini 무료 API로 뉴스/노션 메모 기반 스레드 글 생성 (200~280자) | auto_post.write_post, write_evening_post_from_note |
| F-13 | 스팸 패턴 회피 | 답장 문구 6종 랜덤, 회차당 4개 상한, 답장 간 20~50초 간격 | config.py, comment_bot.py |
| F-14 | 즉시 테스트 발행 | Actions 버튼으로 morning/evening 스타일 즉시 발행 | auto_post.yml (FORCE_WINDOW) |
| F-15 | 첫 줄 후킹 공식 | 후킹 패턴 6종을 날짜 해시로 지정, 스크롤 스토퍼 첫 줄 강제 | auto_post.HOOK_PATTERNS |
| F-16 | 요일별 앵글 | 월~일 7종 앵글로 매일 글의 결 변화 (뉴스 기반 코너에 적용) | auto_post.WEEKDAY_ANGLES |
| F-17 | 발행 안정화 대기 | 컨테이너 생성 후 30초(대댓글 8초) 대기 — 공식 권장 반영 | threads_api.publish_text |
| F-18 | 발행 시간대 판정 통일 | 아침/저녁 모두 "정해진 시(hour) 범위 안이면 즉시 발행" 방식으로 통일. 예전의 날짜별 랜덤 목표 시각 대기 로직은 폐기 | auto_post.should_post_now, current_window |
| F-19 | 아침 코너 "밤사이 AI 소식" | 사건 중심 검색어(정책 발표/서비스 출시/규제/정부 지원/빅테크 업데이트)로 교체, 공감형 후킹 오프닝 → 사건 설명 → 4050 중요성 한 줄 → 질문 없는 따뜻한 마무리의 4단 구조 | auto_post.NEWS_QUERIES, write_post |
| F-20 | 저녁 코너 "AI로 이렇게 바뀌었어요" (반자동) | 노션 "저녁 소재 노트" DB에서 사용여부=미사용 중 가장 오래된 메모를 가져와 상황→AI 활용→변화·결과→실행 팁 구조로 다듬어 발행. 발행 성공 시 해당 메모를 "사용"으로 갱신. 미사용 메모가 없으면 뉴스 기반 "저녁 실전 활용팁"으로 자동 대체 | notion_api.get_unused_evening_note, mark_evening_note_used, auto_post.write_evening_post_from_note |
