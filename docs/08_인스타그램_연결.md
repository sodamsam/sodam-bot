# ⑧ 인스타그램 연결

카드뉴스(저녁 복붙 프롬프트 카드 4장, 아침 AI 브리핑 카드 1장)를 스레드에 올린 직후 **같은 카드를 인스타 피드에도 올린다.** 연결 전에는 아무 일도 하지 않으니(설정이 없으면 건너뜀) 안전하다.

## 코드가 하는 일
- `instagram_api.py`: Instagram API with Instagram Login(`graph.instagram.com`)으로 피드 게시. 여러 장이면 캐러셀(2~10장), 한 장이면 단일 게시물.
- 인스타는 **JPEG만** 받으므로 카드마다 `.jpg` 사본을 함께 저장소에 올려 그 주소를 쓴다(`card_news.save_jpeg_copy`). 카드 크기 1080×1350(4:5)은 피드 허용 비율이다.
- 캡션 = 스레드 본문 + 글 종류별 해시태그(`instagram_api.HASHTAGS`). 스레드 글에는 해시태그를 붙이지 않는다.
- **인스타 발행이 실패해도 스레드 글은 정상 발행**된다(`::warning::`만 남김). 성공하면 `state/posted.json`에 `instagram_id`가 기록된다.
- 토큰(60일)은 `refresh_token.yml`이 스레드 토큰과 함께 매주 자동 연장한다(`GH_ADMIN_TOKEN` 필요, 이미 등록됨). 상태 확인에도 인스타 토큰 점검이 들어 있다(경고 수준).

## 사용자가 할 일 (한 번만)

### 1. 인스타 계정을 프로페셔널로
인스타 앱 → 설정 및 개인정보 → **계정 유형 및 도구 → 프로페셔널 계정으로 전환** (크리에이터 또는 비즈니스, 무료). 개인 계정이면 API로 게시할 수 없다.

### 2. Meta 앱(sodam-bot)에 인스타 연결
1. https://developers.facebook.com/apps → `sodam-bot` → 사용 사례에서 **Instagram**(인스타그램 메시지·콘텐츠 관리)을 추가하고 **API setup with Instagram login**(인스타 로그인 API 설정) 화면으로 들어간다.
2. 필요한 권한: `instagram_business_basic`, `instagram_business_content_publish`.
3. 개발 중 모드이므로 게시할 인스타 계정을 **테스터**로 등록해야 한다: 앱 역할(App roles) → 역할(Roles) → Instagram 테스터 추가 → 인스타 앱에서 초대 수락(설정 → 앱 및 웹사이트 → 테스터 초대).
4. 같은 화면의 **Generate access tokens**에서 계정을 추가(Add account)하고 **Generate token**을 누르면 60일짜리 토큰이 나온다. 그 옆에 **인스타그램 계정 ID**(숫자)도 보인다.

### 3. GitHub Secret 두 개 등록
https://github.com/sodamsam/sodam-bot/settings/secrets/actions/new

| 이름 | 값 |
|---|---|
| `INSTAGRAM_ACCESS_TOKEN` | 2-4에서 받은 토큰 |
| `INSTAGRAM_USER_ID` | 2-4의 인스타그램 계정 ID(숫자) |

### 4. 확인
Actions → "매일 자동 글 발행" → Run workflow → `force_window`=force, `post_type`=**card_prompt** → 실행. **스레드와 인스타에 실제로 올라간다.** 결과는 인스타 앱에서 확인한다. 실패하면 실행 로그의 `인스타 발행 실패` 줄을 보면 된다.

## 문제가 생기면
- `인스타 발행 실패 … 190` / `OAuthException`: 토큰 만료·권한 누락. 2-4에서 토큰을 다시 받아 `INSTAGRAM_ACCESS_TOKEN`을 교체.
- `… 9004` / 이미지 오류: 이미지 주소를 인스타가 못 읽은 경우. 저장소가 Public인지, `cards/` 아래 `.jpg`가 올라갔는지 확인.
- 계정이 프로페셔널이 아니면 `Instagram account is not a professional account` 계열 오류가 난다(1단계).
- 앱이 아직 "개발 중" 모드면 **테스터로 등록된 계정만** 게시할 수 있다(2-3).
